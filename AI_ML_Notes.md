AI & Machine Learning – Learning Notes

1. Introduction to Artificial Intelligence

Artificial Intelligence (AI) is a branch of computer science that focuses on creating machines and software capable of performing tasks that normally require human intelligence.

AI systems can perform tasks such as learning, reasoning, problem-solving, understanding language, recognizing images, and making decisions.

Examples of AI

- Virtual assistants
- Chatbots
- Face recognition
- Recommendation systems
- Self-driving vehicles
- Fraud detection
- Medical diagnosis systems

---

2. Machine Learning

Machine Learning (ML) is a subset of Artificial Intelligence. It enables computers to learn patterns from data and improve their performance without being explicitly programmed for every possible situation.

Basic Machine Learning Process

1. Collect data
2. Clean and prepare the data
3. Select important features
4. Train a machine learning model
5. Test the model
6. Evaluate the results
7. Use the model for predictions

Examples

- Email spam detection
- Product recommendations
- House price prediction
- Customer classification
- Disease prediction

---

3. Deep Learning

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers.

Deep learning is particularly useful when working with large and complex datasets such as images, audio, and text.

Applications

- Image recognition
- Speech recognition
- Natural Language Processing
- Autonomous vehicles
- Medical image analysis
- Generative AI

---

4. AI vs Machine Learning vs Deep Learning

Technology| Meaning
Artificial Intelligence| Broad field of creating systems that perform intelligent tasks
Machine Learning| A method of enabling computers to learn from data
Deep Learning| A type of ML that uses multi-layer neural networks

Relationship

AI → Machine Learning → Deep Learning

Deep Learning is a part of Machine Learning, and Machine Learning is a part of Artificial Intelligence.

6. Introduction to Python

Python is a high-level, interpreted programming language known for its simple syntax and readability.

Python is widely used in:

- Artificial Intelligence
- Machine Learning
- Data Science
- Web Development
- Automation
- Scientific Computing

---

7. Python Variables

A variable is a name used to store a value.

Example:

name = "Sahithi"
age = 19
cgpa = 8.9

Python automatically determines the data type of a variable.

---

8. Python Data Types

Common Python data types include:

- "int" – Integer values
- "float" – Decimal values
- "str" – Text
- "bool" – True or False
- "list" – Ordered and changeable collection
- "tuple" – Ordered and unchangeable collection
- "dict" – Key-value pairs

Example:

age = 19
name = "Sahithi"
student = True
marks = [85, 90, 88]

---

9. Conditional Statements

Conditional statements allow a program to make decisions.

Example:

age = 19

if age >= 18:
    print("Eligible")
else:
    print("Not eligible")

Python commonly uses:

- "if"
- "elif"
- "else"

---

10. Loops

Loops are used to execute a block of code repeatedly.

For Loop

for i in range(1, 6):
    print(i)

While Loop

count = 1

while count <= 5:
    print(count)
    count += 1

---

11. Python Lists

A list stores multiple values in a single variable.

Example:

languages = ["Python", "C", "Java"]

print(languages[0])

Lists are ordered and can be modified.

---

12. Python Functions

A function is a reusable block of code designed to perform a specific task.

Example:

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

Functions improve code organization and reduce repetition.
